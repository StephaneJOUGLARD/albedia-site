# albedia-site

Site vitrine d'ALBEDIA, publié sur [albedia.eu](https://albedia.eu) par déploiement Git depuis
l'hébergement OVHcloud (branche `main`).

Les sources sont dans `_src/` ; le site est régénéré à la racine avec `python3 _src/build.py`.
Méthode de modification détaillée : voir `CLAUDE.md`.
